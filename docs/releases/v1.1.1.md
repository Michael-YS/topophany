# Topophany v1.1.1

Topophany 1.1.1 fixes probe durations when the system clock changes during a
check, including clock corrections observed on WSL.

## Fix

Probe elapsed time now uses Go's monotonic clock. Sample timestamps remain UTC.
Previously, converting the start time to UTC discarded its monotonic reading:
a backward clock step could produce a negative duration, and a forward step
could produce a duration beyond the check's timeout budget. Collectors rejected
these observations with `observation_budget_exceeded`, quarantining valid
results and delaying other observations in the same delivery batch.

The regression test models both backward and forward wall-clock steps without
changing the system clock, and checks that elapsed durations remain valid for
collector ingestion.

## Upgrading

Replace the `topo` binary and restart workers and any collectors that execute
checks. No topology, credential, storage format or API changes are required.
Existing quarantined observations are preserved; the upgrade does not rewrite
their invalid durations or replay them automatically. Healthy pending
observations continue through the normal delivery queue.

Archives are available for Linux, macOS and Windows on amd64 and arm64. Verify
downloads with `SHA256SUMS.txt`.
