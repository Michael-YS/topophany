Topophany — self-hosted network monitoring in the terminal

From where, via which path, reaching what — and on what evidence.

Self-hosted network and service monitoring, read in the terminal. One Go binary, no dependencies, and nothing turns green until a check passes.

03 Architecture

One binary, three roles

topo is the client, the collector and the observer. No CGO, no database, no external modules.

  • binaryclient, collector and worker
  • external Go modulesstandard library only
  • release buildsLinux, macOS, Windows · amd64, arm64
  • tabsmouse included

topothe TUI, with failover

Two collectors, no consensus theatre

Workers send to both and buffer while one is away.

Read-only by design

No remote config API, no remote shell. Topology is local JSON you review.

Bounded, and says so

When a quota fills, probing stops with an error rather than dropping evidence.

04 Probes

What it measures

Native probes, proxy chains, and read-only adapters for tools you already run.

Native probes

checkevidencea pass proves
  • L7
    • http200 · 182 msexpected status, body, headers and egress IP
    • ssh-bannerSSH-2.0 · 38 msan SSH banner, not a login
    • dnsA 192.0.2.10 · 9 msexpected A and AAAA records
  • L6
    • tlsTLS 1.3 · verified · 41 msa verified certificate chain and name
  • L4
    • tcpconnected · 23 msa connection, and nothing behind it
    • udp-echononce echoed · 27 msa random nonce, echoed back
  • L3
    • icmpecho reply · 31 msan echo reply, IPv4 only

Proxy chains

  1. observer
  2. OpenSSH -Wfirst hop, host key verified
  3. HTTP CONNECT
  4. HTTPS CONNECTthe proxy's TLS verified
  5. SOCKS5remote DNS
  6. target

Up to 12 hops. HTTP, TCP, TLS and SSH checks run through every one, in order.

Read-only adapters

  • MihomoGET /proxiesmode, chain and selection, as the core reports them
  • Tailscaletailscale status --jsonpeer online, direct or relayed
  • WireGuardwg show wg0 dumplast handshake and byte counts; keys never kept

What a tool reports is shown as reported, never as an end-to-end pass.

Edges and platforms

  • CloudflareedgeWorkers and Pages; the POP that answered
  • VerceledgeFunctions; the edge and function region
  • Supabaseplatformmanaged services, in their region

An answer is credited to the edge that sent it, never to the origin behind it.

05 Install

Up in a minute

Prebuilt archives, or one go install.

$go install github.com/WhitenWhiten/topophany/cmd/topo@latest

Needs Go 1.26.9 or newer.

Linux, macOS and Windows, amd64 and arm64, with SHA256SUMS.txt.

Latest release
$ git clone https://github.com/WhitenWhiten/topophany $ cd topophany $ go build -trimpath -o topo ./cmd/topo

  2. Start a collector

    Serves a demo on 127.0.0.1:7447.

    $ topo init --dir ./demo $ topo serve --config ./demo/topology.json \ --auth ./demo/auth.json \ --data ./demo/collector-data \ --observer demo

  3. Open the TUI

    In another terminal.

    $topo --credentials ./demo/credentials.json
